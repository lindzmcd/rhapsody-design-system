RHAPSODY EMPLOYEE EMAIL SIGNATURE — deployment notes for IT
===========================================================
Files:
  rhapsody-email-signature.html  — the signature markup (open in a text editor)
  Rhapsody_logo_primary.png      — the logo to host (navy bar + blue wordmark)

Steps:
  1. Host Rhapsody_logo_primary.png at a public URL, then replace
     LOGO_URL_HERE in the HTML with that URL.
  2. Replace the [bracketed] placeholders with directory fields in your
     signature manager (name, title, phone, email).
  3. Paste the HTML into your signature tool / Outlook signature editor.

Design notes (kept minimal on purpose):
  - Logo on the left, thin teal divider, then name / title / contact.
  - No company-name text line (the logo already carries it).
  - No quotes, taglines, banners, or social icons.
  - Poppins with Arial fallback; colors are inline hex (Navy #0B2C47,
    Rhapsody Blue #1A81F4, Teal #23C5BF, Gray #7E858C).
