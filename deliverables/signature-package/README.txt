RHAPSODY EMAIL SIGNATURE PACKAGE
================================================================
Everything needed to roll out the standard Rhapsody email signature.

CONTENTS
  1-IT-Deployment-Guide.txt ............ for IT: host the logo, deploy
                                         org-wide, map directory fields,
                                         handle certifications, test.
  2-Employee-Setup-Guide.txt ........... for staff: set your own
                                         signature in Outlook or Gmail.
  signature-standard.html .............. the default signature template
                                         (HTML, email-client-safe table
                                         layout, Poppins/Arial).
  signature-with-certifications.html ... same, plus a compliance-badge
                                         row for required roles.
  logos/
    Rhapsody_logo_primary.png .......... USE THIS in the signature
                                         (navy bar + blue wordmark, on white)
    Rhapsody_logo_primary.svg .......... vector master of the primary logo
    Rhapsody_logo_white.png ............ all-white wordmark (dark backgrounds)
    Rhapsody_logo_navy.png ............. one-color navy wordmark
    Rhapsody_monogram_blue-navy.png .... R monogram for very tight tools

START HERE: open 1-IT-Deployment-Guide.txt.

Note on certification badges: this package intentionally does NOT include
Cyber Essentials Plus / ISO 27001 artwork. Those are third-party marks,
use the official files issued by the certifying body (via Security /
Compliance), never a recreated version.

Colors: Navy #0B2C47 · Rhapsody Blue #1A81F4 · Teal #23C5BF · Gray #7E858C
