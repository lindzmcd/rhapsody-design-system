Tables

Tables use a navy header row with white text, alternating white and gray-blue rows, and thin light-gray dividers. Highlight the key column or result in blue. No heavy borders.

When a table needs color

Most tables stay monochrome, navy header, alternating rows, and one blue result column, because color-coding data is the charts’ job, not the table’s. The one case that calls for more color is a status or category column, where a small colored tag speeds scanning. Keep the color to that one column, use a single tag color per state, and put dark text on light fills.
