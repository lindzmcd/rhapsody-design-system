Quotes

  • Reduce to one short, powerful line—cut everything that is not the point. Caps: one-line snippets under 60 characters, longer testimonials under 120; if a quote needs more, it needs editing.
  • Set it large using primary or secondary colors only, Rhapsody Blue or navy on light backgrounds, Rhapsody Blue on dark, never the tertiary purple or orange. Hold one accent color across a group of quotes or stats.
  • Highlight in a Rhapsody-colored box with white text, or Rhapsody-colored text on white.
  • Attribution: use the customer’s verified logo (accurate, current, high-res, transparent background) whenever we can; name the customer in small caps only when the logo can’t be used. For several logos, use the bracket treatment.
  • Always wrap the quote copy in opening and closing quotation marks. An oversized decorative mark is an optional accent, not a substitute for them.

A longer testimonial sets the quote on navy, in opening and closing marks, with a soft serif oversized mark as the accent, then attributes it with the name lockup: name, title, company. Match the light device to the message: because this quote is about connection, use Plexus (the connected-network device) offset to the calm side, never behind the copy; see Light devices for choosing between Plexus, Aurora, and Burst. Keep the quote itself tight.
