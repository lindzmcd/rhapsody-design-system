Rhapsody

Embedded in an asset that already shows the logo: the company line is the written name, so the logo isn’t repeated.

  • Order is always name → title → company; never reorder or merge lines.
  • Company line: use the Rhapsody logo in a standalone name card; use the written name “Rhapsody” (Poppins Medium (500), Rhapsody Blue; light blue on dark grounds) when the card sits in an asset that already shows the logo, so the logo never repeats.
  • Titles follow the person’s actual title; don’t abbreviate or retitle for fit; reduce size instead.
  • On light, pair the lockup with the thin-ring portrait.
  • On dark, use the event card pattern: eyebrow, session title, date/time line, then the lockup.
  • Date and time formatting follows Typography → Dates and times.
