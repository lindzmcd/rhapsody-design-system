Layout and spacing

Layouts should always breathe. Two rules keep graphics clean and consistent.

Clear margin (padding)

Keep a clear margin around every graphic of about 6 to 7 percent of the shorter side, with no copy, photo, or logo inside it. For example, roughly a 40 pixel margin on a 600 pixel wide graphic, scaling proportionally. This safe zone keeps content off the edges so the layout always breathes.

Teal separator line

When a graphic borders other content, such as a webpage hero or an email banner seam, a thin teal rule sits along one edge (the bottom by default) to separate it from the content below. On standalone pieces like ads or social posts, no line is needed. Keep it teal only and thin, spanning the full width of the block.

Module accent line (H2 sections)

Section modules led by an H2 open with a short horizontal accent line (“accent bar”) set directly above the heading, or above the eyebrow where one is present. It signals the start of a new content module and gives each section a consistent, engineered entry point. Adopted from the homepage prototype.

Automation

Automate the work around the data.

Teal bar: automation / “automate the work” contexts.

  • Dimensions: 44px wide × 3px tall, 2px corner radius.
  • Spacing: sits above the eyebrow/H2 with about 20–22px below it before the heading.
  • Color carries the section’s pillar meaning: blue (#1A81F4) for infrastructure/“build” contexts, teal (#23C5BF) for automation/“automate the work” contexts. Default to blue when a section is neutral. Never orange. Apply this pairing consistently wherever both paths appear together, in a deck, page, or diagram, so build always reads blue and automation always reads teal.
  • One accent line per module, tied to the primary H2. Do not repeat it on sub-cards within the same module (cards use their own thin top bar where needed).
  • It is decorative structure, not a divider; don’t stretch it full-width.
  • The same device appears on section headers, pillar cards, and case cards, always at the same 44×3 size, so the whole site reads as one system.
