Color

Rhapsody Blue is the primary color, used most prominently. Rhapsody Navy, light blue, and teal are secondary. Purple and orange are tertiary accents, used sparingly. Full-page backgrounds stay white, Rhapsody Blue, or Rhapsody Navy; light gray and gray-blue are for content modules, not full-page fills.

Text color

Body copy uses only white, Rhapsody Navy, or black. Rhapsody Blue is an accent color, never running body copy. Work down the list in order.

  • Rhapsody Navy is the default text color. On light backgrounds, set body copy and headings in Rhapsody Navy (#0B2C47) rather than black. Navy is the on-brand dark and clears contrast on white easily.
  • Black is a fallback, not a default. Reach for black (#050F19) only when navy falls short of a contrast or accessibility requirement for a given pairing, or when print is limited to options that can’t reproduce navy accurately (for example single-color or limited-ink jobs). Otherwise, navy.
  • Rhapsody Blue is the accent on light. Use it for emphasis, links, and one accent word in a headline, not for running body copy.
  • On dark backgrounds, text is white. For a blue accent on navy, use Rhapsody Blue where the element is large enough to read as vibrant (large headlines, sizable graphic elements); drop to light blue (#B4D8FF) for smaller type and small graphic elements, where Rhapsody Blue loses legibility against navy. Light blue is the small-scale, dark-ground counterpart to blue, not a wholesale replacement for it.
  • Not for copy: teal, purple, and orange. Exception: text links in automation contexts may use teal (#23C5BF); see Text links and the CTA arrow in Buttons and CTAs.
  • No tertiary color in type: purple and orange are never used for any heading, eyebrow, or label. The one color exception is an H3, which may take a secondary color (navy, light blue, or teal, contrast permitting). Body copy, captions, and larger headings (H1, H2) stay within the copy colors above.
  • Contrast: minimum 3:1. Digital uses HEX or RGB; print uses CMYK or Pantone.
  • Module backgrounds: light gray (#D9DFE6) and gray-blue (#E8EDF2) fill content blocks such as cards, tables, and panels (including alternating table rows), never a full page. Full-page backgrounds stay white, Rhapsody Blue, or Rhapsody Navy.
The three-color rule, and its exceptions

Do not use more than three brand colors, including primary and secondary, in one layout. Two exceptions: the multicolor dot field, which is its own system and can carry the full dot palette, and data visualizations, where a chart may use additional brand colors when the data needs to be distinguished (see Charts, graphs, and tables). The rest of the layout still observes the three-color rule.

Color accessibility

Type and background combinations must meet a minimum 3:1 contrast ratio. Checking contrast is always your responsibility. A good rule of thumb: navy or white type plus one other color.

Caveats by color

Navy is the default text color on light and black is the permissible fallback; both clear contrast easily on white. The pairings below fall short of 3:1 and are left out of the swatches above. Always check contrast, but as a baseline:

  • Teal is a light color: never white type on teal (2.1:1), and never teal type on white or other light backgrounds (2.1:1). Set dark type on teal, and use teal type only on navy or dark (6.7:1). See Text on teal for minimum sizes.
  • Orange behaves the same on light: white type on orange (2.6:1) and orange type on white (2.6:1) both fail. Use black or navy type on orange; orange type reads on navy (5.5:1). Keep orange as a sparing accent, not body copy.
  • Purple works with white or black type and as type on white, but purple type on navy or black fails (2.4:1). Don't set purple type on dark grounds.
  • Blue clears 3:1 with white type (3.8:1) and as type on navy (3.75:1), but not the 4.5:1 for small body text. So on navy, use Rhapsody Blue only for large or heavy type and sizable graphics; for small type and small graphic elements, use light blue (#B4D8FF), which reads clearly on navy at any size.
  • Never dark on dark: no black type on navy (1.4:1) or navy type on black.

Text on teal

Teal (#23C5BF) is a light color, so it is a background for dark text only. Navy (#0B2C47) reads at 6.7:1 and black (#050F19) at 9:1 on teal, both pass WCAG AA at any size. White text on teal is only 2.1:1 and fails at every size, so a minimum font size cannot make white copy on teal compliant. Never set white or light copy on a teal fill; if a layout needs light text, darken the surface to navy instead of forcing white onto teal.

Minimum sizes for copy on teal

  • Set all copy on teal in navy or black. Body and interface text at least 16px; supporting labels at least 14px; never below 12px on teal.
  • Because only dark text clears the threshold, size is a legibility floor here, not a way to pass contrast: white and light copy stay non-compliant on teal at any size.
  • Same rule for teal buttons: the label is navy (as in the dark-mode primary button), never white.

Rhapsody Blue on navy

On navy (#0B2C47), the two blues split by size. Rhapsody Blue (#1A81F4) reads at 3.75:1, which clears 3:1 for large or heavy type but falls short of the 4.5:1 needed for small body text. Light blue (#B4D8FF) reads at about 9.7:1 and stays legible on navy at any size. So use Rhapsody Blue for large, vibrant moments and light blue for anything small. Light blue is the small-scale counterpart to blue on dark grounds, not a wholesale replacement for it.

When to use which on navy

  • Rhapsody Blue on navy: large headlines and accent words (roughly 24px+, or ~19px bold), plus sizable graphic elements such as large bars, blocks, and big dots, where the blue stays vibrant.
  • Light blue on navy: body copy, captions, labels, secondary and accent lines, thin rules, small icons, and small dots, anything below the large-text threshold.
  • Rule of thumb: if the element is large enough to pass 3:1, Rhapsody Blue is fine; if it is small text that needs 4.5:1, switch to light blue.
  • Don’t rely on size alone to rescue small Rhapsody Blue copy on navy, it stays below 4.5:1; drop to light blue instead.
