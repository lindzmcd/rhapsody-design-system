Pathways: build and automate

There are two ways to work with Rhapsody, and each carries a consistent color so a user always knows which path they are on. Build the infrastructure is Rhapsody Blue; Automate the work is Teal. This is a wayfinding system, not just a section accent: it governs how the website, path-specific content, and journeys are themed, so the color itself signals the path.

The directive

Wherever a surface belongs to a path, carry its pillar color as the cue: the module accent line, the eyebrow, in-context links and buttons, diagrams, and section theming. Hold the color across the whole journey, a page, a deck, a nav branch, so Build always reads blue and Automate always reads teal. Default to blue when a surface is neutral or spans both.

The two pathways

Build the infrastructure

Build on proven interoperability.

Path color: Rhapsody Blue #1A81F4. The blue accent line, eyebrow, links, and icons signal a build surface.

Automate the work

Automate the work around the data.

Path color: Teal #23C5BF. Teal cues the automate surface. The line is teal; keep the eyebrow and heading navy, since teal is not legible as small text on white.

Where the cue appears

  • Website and navigation. Path landing pages and their sections theme to the pillar color, so moving into a Build or Automate branch is visible at a glance.
  • Module accent line. Blue for Build modules, teal for Automate modules (see Layout and spacing for the device spec).
  • Eyebrows and links. In-context kickers, text links, and the CTA arrow take the path color. Feature icons stay in the blue family (navy, Rhapsody blue, light blue), never teal, so on an Automate surface the pillar cue is carried by the accent line, eyebrow, and links, not the icons. On white, teal drops to the line only; keep teal copy off white (see Color, Text on teal).
  • Content and diagrams. Path-specific decks, one-pagers, and diagrams carry the color consistently end to end.

More than two items

When a third pathway is introduced, or the accent device carries more than two items, extend the sequence in this fixed order so coding stays predictable:

1 · Blue
Build
2 · Teal
Automate
3 · Purple
4 · Orange
5 · Light blue
6 · Navy

Blue → teal → purple → orange → light blue → navy. Assign in order and hold each path’s color across its whole journey.

Do
  • Keep Build blue and Automate teal everywhere the paths appear together.
  • Hold a path’s color across its full journey, page, deck, and nav branch.
  • Default to blue for neutral surfaces or ones that span both paths.
  • Add colors in the fixed order only when a genuine third-plus path exists.
Don’t
  • Swap or mix the path colors, or switch a path’s color mid-journey.
  • Set teal as small copy on white; the cue is the line or fill.
  • Invent a new color for a path, or reorder the sequence.
  • Theme a neutral, cross-path surface to one pillar’s color.
