PowerPoint deck template

The official Rhapsody slide deck template (2026), on the current brand: Poppins for headings and body, IBM Plex Mono eyebrows, Rhapsody Navy #0B2C47 grounds, and the approved layout catalog (title, agenda, content, data, quote, timeline, stats and closing slides). It is a PowerPoint file you download and edit in PowerPoint, not a web component — build decks from it rather than from a blank file.

Download

Master file: downloads/Rhapsody-PowerPoint-Template-2026.pptx — 65 slides. Start every Rhapsody deck from this template; never rebuild the layouts, colors or type.

Using it

  • Pick a layout from the catalog and fill in content — don’t alter colors, fonts, or structural elements.
  • Poppins Light/Regular for body, Medium for emphasis; eyebrows and labels in IBM Plex Mono.
  • Keep to three brand colors per slide; flat color only, no gradients.
  • White logo on navy/blue grounds, blue-black logo on light.

The web design system (these cards) governs color, type, logo, devices and patterns; this deck applies that system to slides. For digital display formats see Display ads.
