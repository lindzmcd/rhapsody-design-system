# photos

The approved Rhapsody photo library: about 100 single-person photos, each in two crops (web-size copies; full-resolution originals from the brand team).

- `3x2/<name>-3x2.jpg` (1200×800) — cards, articles, slides, and photo slots in web layouts
- `1x1/<name>-1x1.jpg` (800×800) — portraits, avatars, speaker graphics, and the Rhapsody Blue ring

Use the crop that matches the slot. Don't re-crop through a face, stretch, flip, filter, or tint. These are stock models: never present them as named customers, employees, speakers, or the source of a quote. Licensed for Rhapsody marketing only; don't share the files outside Rhapsody.
