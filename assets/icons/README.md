# icons

A sample of the official FY27 icon library, the only icons to use. The full library (271 icons, each in four versions as SVG and PNG) is on SharePoint: Marketing > Public > _Rhapsody Brand Materials > Brand Package FY27 > Icon Library, open to everyone at Rhapsody. File names are the library's own.

- `light-tile/W_*.png` — Light-background tile: Rhapsody Blue glyph in a gray-blue tile, for white, light gray, and gray-blue grounds
- `dark-tile/D_*.png` — Dark-background tile: light-blue glyph in a white tile at 10%, for navy

Use the files as supplied; never redraw, recolor, or change the stroke.
