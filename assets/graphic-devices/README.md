# Graphic devices (verbatim masters)

PNG copies (1152×648) of the approved device masters. The source of truth, with SVG and Illustrator
files, is the SharePoint **Graphic Devices library**:
https://rhapsodyhealth.sharepoint.com/:f:/r/Shared%20Documents/Marketing/Private/Graphic%20Design/_Asset%20Library/Graphic%20Devices?d=wf6fdf9bcc922469ba66e85bb803d7fed&csf=1&web=1&e=rzllkh
(Marketing > Private > Graphic Design > _Asset Library > Graphic Devices).

Files keep the library's numbering, for example `Fluid Dot-07.png` is `fluid-dot/fluid-dot-07.png`.
Use them as supplied: never rebuild, recolor or trace a device.

## Note on color

These PNG exports read slightly off the brand hex values: navy #002D49, Rhapsody Blue #0083FC, light
blue #ABD9FF, teal #00C9C0 and purple #7B3DED, against #0B2C47, #1A81F4, #B4D8FF, #23C5BF and #7340E4.
This is likely a color-profile conversion on export. Use the SVGs from the library where an exact
match to brand-colored backgrounds matters.
