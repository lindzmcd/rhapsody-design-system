# Rhapsody letterhead (Word)

The starting point for every letter and everyday Word document. One letterhead per office. The
master copies are in SharePoint: Marketing > Private > Graphic Design > Templates > Document
Templates > Letterhead.

| Office | Template (.dotx, for Word) | Document (.docx, for editing and for Claude) |
|---|---|---|
| US Boston | `Rhapsody_Letterhead_US_Boston.dotx` | `Rhapsody_Letterhead_US_Boston.docx` |
| UK Bristol | `Rhapsody_Letterhead_UK_Bristol.dotx` | `Rhapsody_Letterhead_UK_Bristol.docx` |
| APAC Shanghai | `Rhapsody_Letterhead_APAC_Shanghai.dotx` | `Rhapsody_Letterhead_APAC_Shanghai.docx` |

The .dotx files are as supplied (November 2026). The .docx files are made from them by changing
only the package content type (template to document), so they open as ordinary documents; the
same .docx files are bundled in the brand skill (`assets/letterhead/`).

- Page 1: logo, tagline, hairline; footer with the office address, phone, email and website.
- Page 2 and on: small logo and hairline; footer "rhapsody.health · Page N".
- Arial 11pt, Rhapsody Navy #0B2C47; US Letter; 1in side margins.

Technical documents (white papers, release notes, security advisories) use the templates one
folder up instead.
