# Rhapsody Display Ads template

A Claude Design canvas template covering every IAB display placement from one
shared control set (ground toggle + headline / accent / CTA copy):

- 1200×200 event-app sponsorship
- 970×250 billboard, 728×90 leaderboard
- 300×250 MPU, 300×600 half page, 160×600 skyscraper, 320×50 mobile
- 800×400 sponsor logo tile (dark + light)

Built on the 2026 guideline: Poppins + IBM Plex Mono, navy #0B2C47 / blue
#1A81F4 grounds, light-blue #B4D8FF accent tail, teal #23C5BF seam, one
device per ad, one action per ad.

Live canvas (view / edit / export PNG-PDF):
https://claude.ai/code/artifact/77b33d86-1d42-4ebe-b235-8e81014a9824

`DisplayAds.dc.html` is the source Design Component; `assets/` holds the
logos, monogram, dot-field and photo it references.
