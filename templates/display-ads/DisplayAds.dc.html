Rhapsody display ads
Paid media and sponsorship banner template
One headline, one accent tail, one destination — rendered across every placement Rhapsody buys. Copy, ground and CTA are tweakable; the lockup rules are not. Every format uses the same read order: mark, separator, headline, action.
Minimum type
13px at delivered size. Author oversized formats at 2× and scale down — never set 8px type to fit more words.
One device only
Photo, dot field or nothing — one per ad, always clear of the copy. Below 300px wide, nothing.
Accent tail
The headline's last phrase carries the only color. Light blue on navy, navy on blue — teal on blue does not hold.
One action
A pill button where the label reads at 13px or more; an arrow chip everywhere else. Never both.
