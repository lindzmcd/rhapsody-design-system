RHAPSODY LOGO — NAVY UPDATE (FY26 rebrand)
==========================================
The former black in the logo has been replaced with Rhapsody Navy (#0B2C47).
Blue (#1A81F4) is unchanged. Folders/files renamed black -> navy.

WHAT CHANGED
  Rhapsody logo - black      ->  Rhapsody logo - navy       (one-color navy)
  Rhapsody logo - blue-black ->  Rhapsody logo - blue-navy  (navy bar + blue letters)
  black monogram R           ->  navy monogram R
  black blue monogram R      ->  navy blue monogram R
Unchanged (no black present): blue-white and white logo sets, white/white-blue monograms.

SOURCE
  Recolored from your Illustrator EPS masters. Vectors (.svg/.eps) were rebuilt
  cleanly and are fully scalable; brand colors are set to the exact hex values.
  Monograms were derived from the wordmark vector (bar + R), so you now have
  .svg and .eps monogram masters, which you previously did not.

FILES PER LOGO FOLDER
  .svg              vector master (transparent)
  .eps              vector master (print), navy + blue exact
  -300.png/.jpg     300 dpi  (wordmark 1250x417 px)   png transparent / jpg white bg
  -72.png/.jpg      72 dpi   (wordmark 300x100 px)

MONOGRAMS
  .svg / .eps       scalable masters
  -300.png/.jpg     600x600 px  (avatars, hi-res)
  -72.png/.jpg      128x128 px  (favicon / web)

PRINT COLOR NOTE
  No official Pantone/CMYK navy was provided, so the EPS uses RGB #0B2C47.
  If you have the brand's official CMYK or Pantone navy, swap it in the .eps
  before print use.

Colors: Rhapsody Navy #0B2C47  |  Rhapsody Blue #1A81F4
